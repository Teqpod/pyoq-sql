pyoq.descriptors

The generated tables, columns and relationships, and what each carries.

These are the types generation produces. You rarely construct one: you import TITLES from your generated package and it is a TableDescriptor, TITLES.ID is a ColumnDescriptor. This page is what those objects hold.

TableDescriptor

dataclass — one table, and the row type it reads back as.

FieldWhat it holds
database_nameThe table’s name in the database.
schema_nameIts schema, where the dialect has schemas.
catalog_nameIts catalog, where the dialect has catalogs.
row_typeThe class one row reads back as.
COLUMNSEvery column the table declares, in declaration order.

ColumnDescriptor

dataclass — one column, and everything a statement needs to know about it.

FieldWhat it holds
database_nameThe column’s name in the database.
nullableWhether the database allows null here.
writableWhether a statement may write to it.
has_defaultWhether the database fills it in when a write leaves it out.
generatedWhether the database computes it.
scalar_familyThe broad type family, which decides what it can be compared with.
table_name, schema_name, catalog_nameWhere the column lives.
field_nameThe Python name it is reached by.
value_typeThe Python type one value reads back as.

A column is also an expression, so everything on Expression applies to it.

KeyDescriptor

dataclass — one key of a table.

FieldWhat it holds
kindWhich sort of key it is.
column_namesThe columns it is made of, in order.
database_nameThe key’s own name, where the database gives it one.

RelationshipDescriptor

dataclass — one foreign key, from either end.

FieldWhat it holds
source_table, source_columnsThe side holding the key.
target_table, target_columnsThe side it points at.
source_schema, source_catalogWhere the source sits.
target_schema, target_catalogWhere the target sits.
database_nameThe constraint’s name.
on_update, on_deleteWhat the database does to the child when the parent moves or goes.
directionWhich way this descriptor follows the key.
cardinalityWhether following it yields one row or many.
optionalWhether the key may be null, so the relation may be absent.
target_row_typeThe class a related row reads back as.

Pass one to on_key(...) and the join condition is taken from the schema rather than written out.

RelationDirection

enum of str — which way a foreign key is being followed.

MemberValueMeans
FORWARD"forward"From the table holding the key to the one it points at.
REVERSE"reverse"The other way, from the target back to the rows referring to it.

RelationCardinality

enum of str — how many rows following a relation yields.

MemberValue
TO_ONE"to-one"
TO_MANY"to-many"

Absence

Three names distinguish “no value given” from “the value null”.

NameMeans
UNSETThe single value meaning nothing was supplied. A write leaving a column UNSET does not mention it, so the database applies its default.
UnsetTypeThe enum UNSET belongs to, for annotating a parameter that accepts it.
MissingA relation that was not fetched. Reading it raises RelationNotLoadedError rather than pretending it is empty.
PresentA relation that was fetched, holding what came back.

JSON values

NameWhat it is
JsonScalarThe scalar types a JSON document can hold.
JsonValueAny JSON value, scalars and the containers built from them.

UNSET and UnsetType are also exported from pyoq.unset, which is where they are defined, for a caller that wants them without the rest of this package.
