pyoq.errors

Everything PyOQ raises, and what each one means.

Every error PyOQ raises inherits from PyOQError, so one except catches all of them and nothing else.

Python
from pyoq.errors import PyOQError

They are grouped by what was being done at the time. A base class in each group is raised only through the errors under it.

PyOQError

Everything below inherits from this, so one except catches anything PyOQ raises and nothing it does not.

Base class for package errors.

ErrorRaised when
CommandErrorcommand execution failures
ConfigurationErrorconfiguration failures
ExpressionErrorquery expression failures
HydrationErrorrow hydration failures
NamingErrorgenerated-name failures

PolicyViolationErrorA statement asked for something its policies do not allow
QueryErrorquery model failures
RelationErrorrelation graph failures

SchemaErrorschema model failures
