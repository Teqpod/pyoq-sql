pyoq.generation

The pipeline that writes the generated package, and what owns each file.

What pyoq generate drives. Generation is deterministic, validated before anything is written, and atomic: a run either replaces the package or leaves it as it was.

GeneratedTypesRenderer is also exported from pyoq.generation.rendering.
