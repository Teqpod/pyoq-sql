pyoq.query.sqlite

Compiling, connecting and running against SQLite.

Each dialect fills in the same roles, so everything above it is written once. You reach these only to assemble a database by hand; connect puts them together for you.

SQLite has no asynchronous package: the driver does not block on a network, so there is nothing to await.
