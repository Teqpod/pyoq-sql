pyoq.query expressions

Every comparison, operator and helper a column offers.

Everything on this page is a method of Expression, and every generated column is one. TITLES.PRICE.gt(10) is a Condition, which is what where and having take.

Python
from decimal import Decimal

dsl.select(TITLES.NAME).from_(TITLES).where(
    TITLES.PRICE.gt(Decimal("10.00")).and_(TITLES.NAME.starts_with("A"))
)

A comparison returns a Condition; an operator returns another Expression, so they chain. Nothing here interpolates a value into SQL: every value becomes a bound parameter.

Naming and ordering

MethodWhat it means
as_(name)Names the value in the result, which is what a row is keyed by.
asc()Ascending order, as an order term.
desc()Descending order.

Equality

Both sides must be the same family of type, so a text column cannot be compared with a number.

MethodWhat it means
eq(other)Equal to.
ne(other)Not equal to.
is_distinct_from(other)Differs, counting null as a value rather than as unknown.
is_not_distinct_from(other)The same, counting two nulls as equal.

Ordering comparisons

Only for values with an order.

MethodWhat it means
lt(other)Less than.
le(other)Less than or equal to.
gt(other)Greater than.
ge(other)Greater than or equal to.
between(lower, upper)Within the two bounds, inclusive.
not_between(lower, upper)Outside them.

Membership

MethodWhat it means
in_(*values)Equal to any of the values, which may be expressions or a subquery.
not_in(*values)Equal to none of them.

Nulls and truth

MethodWhat it means
is_null()Holds no value.
is_not_null()Holds one.
is_true()True, distinguished from null.
is_false()False, distinguished from null.

Text

MethodWhat it means

not_like(pattern)Does not match it.
contains(value)Contains the substring.
starts_with(value)Begins with it.
ends_with(value)Ends with it.
lower()In lower case.
upper()In upper case.
length()How long the text is.
concat(other)This value followed by the other.

Arrays

For a column whose values are arrays. Availability differs by dialect; a dialect that cannot express one refuses while the statement is being built.

MethodWhat it means
has(value)The array holds the value.
lacks(value)It does not.
contains_all(values)It holds every one of them.
contained_by(values)Every element of it is among them.
overlaps(values)The two share at least one element.
append(value)The array with the value added at the end.
prepend(value)With it added at the front.
concat_array(values)The two arrays joined.
without(value)With every occurrence of the value removed.
replacing(value, replacement)With each occurrence swapped for another.
element(*position)One element, by position, or nothing where there is none.
length_along(dimension)How long the array is along one dimension.
dimensions()How many dimensions it has.

JSON

A path is given as the segments leading to it: json_get("address", "city"), and an integer segment indexes an array.

MethodWhat it means
json_get(*path)The value at the path, as JSON.
json_text(*path)The value at the path, as text.
json_keys()The keys the document holds.
json_length(*path)How many entries are at the path.
json_has(*path)Whether anything is at the path.
json_contains(value)Whether the document contains the value.
json_set(*path, to=...)The document with the path set, whether or not it was there.
json_insert(*path, to=...)Set only where nothing was there.
json_replace(*path, to=...)Set only where something was.
json_merge(value)The two documents merged.
json_concat(value)The two joined.
json_remove(*path)The document without what was at the path.

Condition

What a comparison returns, and what where, having and on take.

MethodWhat it means
and_(other)Both hold.
or_(other)Either holds.
not_()The negation.

Passing several conditions to where combines them with and_ already, so and_ is for the times a condition is built somewhere else.

RowValue

Columns compared together, as wide as the tuples compared against them. Use row(...) to build one.

Python
from pyoq.query import row

row(TITLES.PUBLISHER_ID, TITLES.NAME).in_((1, "Dune"), (2, "Emma"))
MethodWhat it means
eq(values)The row equals the tuple.
ne(values)It does not.
lt(values), le(values), gt(values), ge(values)Ordered comparison, left to right.
in_(*rows)The row is one of those given.
not_in(*rows)It is none of them.

CaseBuilder and CaseBranches

A case with no branches is not a value yet, so case() returns a CaseBuilder and only when makes it one.

Python
from pyoq.query import case

case().when(TITLES.PRICE.gt(20), "dear").otherwise("cheap")
MethodOnWhat it does
when(condition, result)bothAdds a branch, and fixes the type the whole case answers.
otherwise(result)CaseBranchesThe value when no branch matched. The case cannot be null.
end()CaseBranchesEnds without a fallback, so the case may be null.

Windows

A window function means nothing until it is given a window to look through.

Python
from pyoq.query import rank

rank().over().partition_by(TITLES.PUBLISHER_ID).order_by(TITLES.PRICE.desc())

WindowFunction.over(window=None) and AggregateExpression.over(window=None) both return a Window, which is already usable and which these refine:

MethodWhat it does
partition_by(*expressions)Restarts the function for each group.
order_by(*terms)The order within a partition.
rows(start, end=None)A frame counted in rows.
range_(start, end=None)A frame counted in values.
groups(start, end=None)A frame counted in peer groups.
exclude(exclusion)Leaves part of the frame out, named by FrameExclusion.

Frame edges come from preceding, following, current_row, unbounded_preceding and unbounded_following. See functions for those.
