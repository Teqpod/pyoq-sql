pyoq.query functions

Aggregates, window functions, and everything else the query package offers.

Every callable pyoq.query exports. These build parts of a statement; the methods on a column are on expressions.

Python
from pyoq.query import count, rank, coalesce

Aggregates

Collapse a group of rows into one value. Each can also be used over a window with .over(...).

FunctionWhat it builds
count(expression=None, *, distinct=False)How many rows, or how many hold a value. distinct=True counts each value once.
sum_(expression)The total. Named with a trailing underscore, because sum is a built-in.
average(expression)The mean.
minimum(expression)The smallest value in the group.
maximum(expression)The largest.
json_agg(expression)The rows of a group gathered into one JSON array.
json_object_agg(member, value)The rows of a group gathered into one JSON object, named by a column.

Window functions

Each means nothing until .over(...) gives it a window. See expressions for what a window is refined by.

FunctionWhat it builds
row_number()Which row this is in its window, counting from one, ties broken.
rank()The position of this row, where ties share a position and leave a gap.
dense_rank()The same, where ties leave no gap.
percent_rank()How far through its window this row sits, from zero to one.
cume_dist()The share of the window at or before this row, above zero to one.
ntile(buckets)Which of this many equal buckets the row falls in.
lag(expression, offset=1)The value this far back in the window, or null before its start.
lead(expression, offset=1)The value this far ahead, or null past its end.
first_value(expression)The value in the first row of the window, or null when it is empty.
last_value(expression)The value in the last row the frame reaches, which the frame decides.
nth_value(expression, position)The value this far into the window, counting from one.
named_window(name)A window written once in a query and looked through by several rows.

Frame edges

What rows, range_ and groups take as bounds.

FunctionWhat it builds
current_row()The row being measured.
preceding(distance)This far back from it.
following(distance)This far ahead of it.
unbounded_preceding()Every row before this one, however many there are.
unbounded_following()Every row after it.

Choosing between values

FunctionWhat it builds
coalesce(first, *rest)The first argument that is not null.
nullif(first, other)The first argument, unless it equals the second, in which case null.
greatest(first, *rest)The widest of its arguments.
least(first, *rest)The narrowest.
case()Starts a case, whose type is fixed by the result of its first branch.

JSON and arrays

FunctionWhat it builds
json_array(*values)A JSON array holding these values, in the order they are written.
json_object(members)A JSON object with these members, in that order.
json_elements(document, *, alias)The elements of a JSON array, read one row at a time, as a source to select from.
array_of(*values)An array holding these values, in the order they are written.

Starting a statement

The unbound forms. The DSL offers the same names already bound to a database.

FunctionWhat it builds
select(*values)A SELECT over the values named.
select_from(table)Every column the table declares, in the order it declares them.
insert_into(table, *columns)An INSERT. Naming columns fixes the order values are given in.
update(table)An UPDATE.
delete_from(table)A DELETE.
call(name, *arguments, schema=None, catalog=None)Runs a stored procedure, with its arguments bound like any other value.

Sources and projections

FunctionWhat it builds
table_source(table, *, alias=None)A table as something to select from, optionally under another name.
alias(expression, name)Names a value in the result.
ascending(expression)An ascending order term.
descending(expression)A descending one.

Common table expressions

FunctionWhat it builds
common_table(name, query, *, columns=(), recursive=False)A query named once and referred to by name.
recursive_table(name, *columns)Declares a recursive common table, so its own term can read it.
column(name, value_type)One column of a recursive common table, and what it holds.

Subqueries

FunctionWhat it builds
exists(query)Whether the query returns any row at all.
not_exists(query)Whether it returns nothing at all.

Values and columns

FunctionWhat it builds
bind(value, *, sensitive=False)A value as a bound parameter. sensitive=True keeps it out of diagnostics.
field(value_type, database_name, *, table_name=None, ...)A column PyOQ did not generate, described by hand.
row(*expressions)Several columns compared as one, the way a composite key is one key.
excluded(column)The value a conflicting insert would have written, for use in the update that resolves it.
cast(expression, target)The expression as another type, computed by the database.
routine_output(value_type, name, *, nullable)Describes a reflected routine output without losing its nullability.

Escape hatches

For what the model does not cover. A template names its expressions, which are still bound, so a value never enters the SQL as text.

FunctionWhat it builds
raw(value_type, template, **expressions)An expression written out, and what it answers with.
raw_condition(template, **expressions)The same, answering true or false.
vendor_function(value_type, name, *, dialects=(), ...)Declares a function this database has, and what it answers with.
vendor_predicate(name, *, dialects=())Declares one that answers true or false.
