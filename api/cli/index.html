APIs

pyoq.cli

Running the command line from Python, and what each exit code means.

The command line as a Python entry point. Command line covers the commands themselves and their arguments; this is how to invoke them from code, which is what a test or a wrapper script wants.

The package installs two commands, pyoq and pyoq-after-migration, and python -m pyoq runs the same thing through pyoq.__main__.

main

Python
main(
    arguments: Sequence[str] | None = None,
    *,
    services: CommandServices | None = None,
    output: IO[str] | None = None,
    error: IO[str] | None = None,
) -> int

Runs one command and returns its exit code rather than exiting, which is what makes it usable from a test.

ArgumentWhat it is for
argumentsThe words after pyoq. Omitted, it reads sys.argv.
servicesThe services the command runs against, so a test can supply its own.
outputWhere ordinary output goes. Defaults to standard output.
errorWhere errors go. Defaults to standard error.
Python
from pyoq.cli import ExitCode, main

assert main(["generate", "--check"]) == ExitCode.SUCCESS

run

Python
run(arguments: Sequence[str] | None = None) -> NoReturn

The same, but exits the process with that code rather than returning it. This is what the installed pyoq command calls, and it never returns.

CommandServices

dataclass — what a command runs against, in pyoq.cli.services. Passing your own is how a test drives a command without a database.

FieldWhat it does
generationRuns generate.
inspectionRuns inspect.
snapshotRuns snapshot.
driftRuns drift.

The same type is accepted by after_migration, which runs two of those steps.

ExitCode

enum of int — what the process exits with, so a shell can tell one failure from another.

MemberValueMeans
SUCCESS0The command did what was asked.
COMMAND_FAILED1It ran and reported a failure, such as generated output being out of date.
USAGE2The arguments were wrong.
CONFIGURATION3Configuration was missing, unreadable, or invalid.
UNAVAILABLE4The command is not available for this dialect or this build.

Because the members are integers, main(...) == 0 works, and a shell reading $? sees the same numbers.
