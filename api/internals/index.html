Internals

Everything else the package defines, and why none of it is a contract.

Python has no way to stop you importing these, so they are listed rather than left for you to find. None of them is a supported import. They are how the package is built rather than what it offers: they carry no compatibility promise, and any of them may change or go in a patch release.

What is supported is All references and the pages beside it. If something here looks like the only way to do what you need, that is worth raising as an issue rather than importing.

Type variables are left out: Value1, ResultRow and their kind are generic parameters rather than things to call.
