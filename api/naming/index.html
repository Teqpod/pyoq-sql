pyoq.naming

Turning schema names into Python names, without two of them colliding.

Generation has to name things. Two tables can differ in the database and agree once made into Python identifiers, so names are resolved as a whole scope at a time rather than one at a time, and a collision is reported with every name involved.

NamingPolicy

dataclass — resolves complete naming scopes without retaining mutable state.

MethodWhat it does
resolve(scopes)Every name in every scope, or a collision naming all of them.

The pieces

NameWhat it holds
NamingScopeOne scope: its name, the style its names take, the requests in it, and reserved_names nothing may take.
NameRequestOne name wanted: its key, and the source it came from.
ResolvedNameOne name settled: its scope, key, source and the python_name chosen.
NamingResultEvery resolved name. get(scope, key) reaches one.
NameCollisionTwo or more requests that would take the same name: the scope, the python_name wanted, and every request that wanted it.

A collision raises NamingCollisionError, which carries every collision in the batch rather than the first one found.

PythonNameStyle

enum of str — which form a scope’s names take.

MemberValueUsed for
SNAKE_CASE"snake-case"fields and functions
PASCAL_CASE"pascal-case"classes
UPPER_SNAKE_CASE"upper-snake-case"table constants
