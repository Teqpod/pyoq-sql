pyoq.query.postgres

Compiling, connecting and running against PostgreSQL.

Each dialect fills in the same roles, so everything above it is written once. You reach these only to assemble a database by hand; connect puts them together for you.

The asynchronous pieces are in pyoq.query.postgres.aio, listed at the end.

The execution monitor

PostgresExecutionMonitor is not exported, but PostgresCursorSession names it in its signature. It is a server-side statement timeout together with a watchdog that ends a statement the timeout does not reach, which is how a timeout and a cancellation get to a connection that is already busy. It lives in pyoq.query.postgres.commands.
