APIs

pyoq.diagnostics

What a unit of work ran, how often, and what it cost.

What a unit of work ran, how often, and what it cost. Nothing here is on by default: a database reports only when it is wrapped in one of the operations below. See Diagnostics for the workflow.

Watching a scope

Python
from pyoq.diagnostics import QueryScope, QueryBudget, ScopedOperations

scope = QueryScope(budget=QueryBudget(maximum_queries=20))
operations = ScopedOperations(database, scope)
NameWhat it does
QueryScopeOne request’s worth of work, watched and bounded. record(statement) refuses the one that exceeds the budget; repeated(threshold=2) reports shapes run more than once.
QueryBudgetA ceiling on one scope’s work: maximum_queries and maximum_repeats. Exceeding it raises QueryBudgetExceededError.
QueryObserverThe same counting without a ceiling, kept within a fixed budget of memory.
ScopedOperationsA database that reports every statement to a scope before running it.
AsyncScopedOperationsThe asynchronous counterpart, counting at the same point.

Reporting statements

NameWhat it does
InstrumentedOperationsA database that reports every statement it runs.
AsyncInstrumentedOperationsThe asynchronous counterpart, reporting at the same point.
EventSinkSomewhere for events to go. record(event) is the whole protocol.
CollectingSinkA sink that keeps what it is given, for a caller that wants to look afterwards. clear() empties it.
EventPolicyWhat an event may carry beyond the shape: include_values, include_failure_detail, slow_after. Values are left out unless asked for.

An event is one of StatementStarted, StatementFinished or StatementFailed, and StatementEvent is any of the three.

Shapes

A shape is a statement with its values and their number taken out, so the same query issued a hundred times is one shape.

NameWhat it does
query_shape(sql)The shape of a statement, remembered while it keeps being asked for.
normalize_sql(sql)Reduces a statement to the shape it shares with its repetitions.
QueryShapeThe sql of a shape and its digest.
RepeatedQueryOne shape a scope ran more than once, and where from. describe() reads it back.
calling_site(...)The nearest frame that is not PyOQ’s own, which is what a report points at.
CallSiteWhere that was: file, line, function.
forget_shapes()Empties the cache, which only a test measuring it should need.
shape_cache_metrics()How well the shapes being asked for are already known.
CacheMetricshits, misses, held, capacity.

Metrics

NameWhat it does
metrics_of(pool, observer=None)A reading taken now, from a pool and optionally from what it has run.
DatabaseMetricsCounts and nothing a query was asked about: connections open, idle and checked out, whether the pool is closed, statements, shapes.
reportable_values(statement, policy)The values an event may carry, which is none of them by default.

Defaults

NameWhat it sets
DEFAULT_REPEAT_THRESHOLDHow many executions make a shape worth reporting.
DEFAULT_SHAPE_LIMITHow many shapes an observer keeps.
DEFAULT_SITE_LIMITHow many call sites it keeps per shape.
