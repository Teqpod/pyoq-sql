pyoq.query

The statement model, the enums it is written in, and the tree it compiles to.

The query model itself. These are the statements the DSL wraps: the same objects, without a database attached. Build one here and run it with dsl.fetch(...).

The pages beside this one cover what a column offers (expressions) and what the package exports as callables (functions).

SelectQuery

A SELECT, unbound. Every method returns a new query.

Sources and joining

MethodWhat it does
from_(source)Where the rows come from.
distinct(enabled=True)Removes duplicate rows.
join(source), inner_join(source)An inner join, qualified by what follows.
left_join, right_join, full_joinOuter joins, each qualified by what follows.
semi_join(source)Rows that have a match, without bringing it back.
anti_join(source)Rows that have no match.
cross_join(source)Every combination, so nothing qualifies it.
natural_join, natural_left_join, natural_right_join, natural_full_joinMatched on every column both sides name alike.

Narrowing, grouping and ordering

MethodWhat it does
where(condition)Keeps rows the condition holds for.
group_by(*expressions)Collapses rows that agree on them.
having(condition)Keeps groups the condition holds for.
window(*specifications)Names windows the query then looks through by name.
with_(*common_tables)Attaches common table expressions.
order_by(*terms)The order rows come back in.
limit(value), offset(value)How many, and from where.

Locking rows

What a statement asks the database to hold while it reads. A dialect that cannot express one refuses while the statement is being built.

MethodWhat it asks for
for_update()The rows, exclusively.
for_no_key_update()The rows, allowing a key to be read.
for_share()The rows, shared with other readers.
for_key_share()The weakest lock, guarding the key alone.
nowait()Fail rather than wait for a lock someone else holds.
skip_locked()Skip rows someone else holds, rather than waiting.
of(*targets)Lock only the tables named, not everything joined.

Query

What every query is, whatever built it.

MethodWhat it does
as_subquery(alias)The query as something to select from.
as_lateral(alias)The same, able to see the rows beside it.
as_common_table(name, *, columns=(), recursive=False)The query named once and referred to by name.
union(other), union_all(other)Rows from either, duplicates removed or kept.
intersect(other)Rows both return.
except_(other)Rows the first returns and the second does not.
order_by(*terms), limit(value), offset(value)Applied after a set operation.

SetQuery

What a set operation returns. Offers order_by, limit and offset, which apply to the combined result rather than to either side.

Joining steps

JoinStep is a join waiting to be told how the two tables line up.

MethodWhat it does
on(condition)The predicate the rows are matched by.
using(*columns)Matched on columns both tables name the same way.
on_key(relation)Matched on the foreign key the schema already declares.

SemiJoinStep, from semi_join and anti_join, offers on(condition) alone.

Writing

InsertStatement:

MethodWhat it does
values(*values)One row, in the order the columns were named.
values_many(rows)Many rows from one iterable.
on_conflict_do_nothing(*targets)Skips a row that would collide.
on_conflict_do_update(*targets)Updates the existing row instead.

ConflictUpdate, from the last of those, offers set(column, value) and where(condition).

UpdateStatement offers set(column, value) and set_values(values, *columns), and both it and DeleteStatement are ScopedStatements:

MethodWhat it does
where(condition)Which rows are meant.
all_rows()Says every row is meant, which is how a statement without a where may run.

MutationStatement is what every write can finish with:

MethodWhat it does
returning_all()Every column the table declares.
returning(*values)The columns or expressions named.

ReturningStatement is what those return, and WriteStatement and WriteColumn are what a write and its target column are as a model.

Nodes a dialect is handed

These are not exported from pyoq.query, but a dialect’s expression compiler names them in its signatures, so they are here to be looked up. They live in pyoq.query.nodes, except JsonElementsSourceNode, which is in pyoq.query.select_nodes.

NodeWhat it isHolds
ArrayNodeAn array asked about against something else.operation, expression, operands
ArrayConstructNodeAn array built out of the values around it.elements, element_type
ArrayElementNodeOne element of an array, counted the way the value it reads counts.expression, indexes
ArrayLengthNodeHow many elements an array holds, in one dimension or in all.expression, dimension
ArrayDimensionsNodeHow many dimensions an array has.expression
JsonNodeReading inside a JSON value, by a path each dialect spells its own way.operation, expression, path
JsonBuildNodeA JSON value built out of the values around it.kind, arguments
JsonWriteNodeA JSON document with something written into it.operation, expression, value, path
JsonKeysNodeThe members an object has, as a JSON array of their names.expression
JsonContainsNodeWhether one JSON value holds another.expression, value
JsonElementsSourceNodeThe elements of a JSON array, read one row at a time.expression, alias
FrameNodeThe rows a window function reads, narrower than the window itself.kind, start, end, exclusion
