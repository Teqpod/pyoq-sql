pyoq.query.execution

Running a compiled statement: operations, pooling, streaming and bulk writes.

Dialect-neutral execution. QueryOperations is what a Database is underneath, and what every framework adapter hands you. The asynchronous counterparts live in pyoq.query.execution.aio under the same names with Async in front.

QueryOperations

What a statement is run against.

MethodWhat it returns
one(query, *, control=None)Exactly one row, raising when there is not exactly one.
one_or_none(query, *, control=None)One row, or nothing.
many(query, *, control=None)Every row.
scalar(query, *, control=None)The single column of the single row.
execute(statement, *, control=None)An ExecuteResult for a write.
execute_all(statements, *, budget=None, control=None)Several statements, optionally under an OperationBudget.
plan_bulk(statement)The BulkPlan a bulk write would carry out.
execute_bulk(statement, *, control=None)Runs that plan, returning a BulkResult.
execute_chunks(plan, control)Runs a plan made elsewhere.
many_bulk(statement, *, control=None)Every row a bulk write returned.
last_inserted_id(cursor)The id the database assigned, where it says.

AsyncQueryOperations is the same surface, awaited.

Controlling a run

NameWhat it holds
ExecutionControltimeout, a cancellation_token, and progress_steps.
CancellationTokencancel() asks a running statement to stop, cooperatively.
OperationBudgetmaximum_operations, a ceiling on one execute_all.

Cancellation is cooperative: it raises QueryCancelledError at the next checkpoint rather than killing a connection.

What a statement compiles to

NameWhat it holds
CompiledQueryThe sql, its parameters, which of them are sensitive, the statement_kind, and the row_types it answers with.
CompilationContextWhat a dialect renders through: bind(node), bind_page_value(value), structural_text(text), and result(sql, statement_kind, node).
StatementKindUNKNOWN, SELECT, INSERT, UPDATE, DELETE, DEFINITION, CALL.
ParameterStyleHow a driver wants its placeholders: QMARK, NUMERIC, FORMAT.
ExecuteResultrows_affected, and last_inserted_id where the database says.
StatementProviderThe protocol a compiler accepts: anything that can give a statement node. In pyoq.query.statements.

Bulk writes

NameWhat it holds
BulkPlannerplan(statement) splits a write into the fewest statements a parameter limit allows.
BulkPlanThe chunks that plan holds.
BulkChunkOne statement, and which rows of the original it covers: start, length.
BulkResultThe results each chunk gave, and the row_counts they add up to.
WriteProviderAnything that can give a write node, which is what these accept.

Pooling

NameWhat it does
ConnectionPoolcheckout() takes a lease, close() ends the pool, and reset, validate, dispose, acquire_for_lease, release_from_lease are what a dialect fills in.
ConnectionLeaseOne connection borrowed. invalidate() says it must not go back.
ConnectionFactoryWhat opens a connection when the pool needs one.
PoolPolicymaximum_size, minimum_size, checkout_timeout.
PoolStatsopen_connections, idle_connections, checked_out_connections, closed.

Streaming

NameWhat it does
RowStreamRows read a piece at a time. close() ends it.
StreamPolicybatch_size, and the control the read runs under.
StreamResourceWhat the stream holds while it runs, released by close().
CursorSessionA cursor held open across batches: fetch_batch(size), checkpoint(), close().

Transactions and cursors

NameWhat it does
TransactionStateWhose connection this is and what may use it: require_current, require_scope, require_owner, adopt, release, invalidate, next_savepoint, close_stream, release_stream.
DatabaseCursorThe driver cursor PyOQ expects: fetchall(), fetchmany(size).
fetch_all(cursor)Every row a cursor holds.

The asynchronous package

pyoq.query.execution.aio exports AsyncQueryOperations, AsyncConnectionPool, AsyncConnectionLease, AsyncConnectionFactory, AsyncCursorSession, AsyncDatabaseCursor, AsyncRowStream, AsyncStreamResource, AsyncTransactionState and fetch_all. Each is its synchronous counterpart with the methods that reach the database awaited.
