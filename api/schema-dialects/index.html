pyoq.schema dialects

Opening a connection and reading a schema, per database.

Each dialect supplies the same three pieces, and pyoq.schema re-exports them all. Reach for one directly only when you want a single dialect without the others.

PostgreSQL

In pyoq.schema.postgres.

PostgresConnectionProvider

dataclass

Opens the connection a schema is read through.

Python
PostgresConnectionProvider()
MethodReturns
open(configuration: 'Configuration')AbstractContextManager[Connection[tuple[object, ...]]]

PostgresSchemaInspector

dataclass

Reads the catalog into a snapshot.

Python
PostgresSchemaInspector()
MethodReturns
inspect(connection: 'Connection[tuple[object, ...]]')SchemaSnapshot

PostgresSchemaSource

dataclass

Loads a whole snapshot: opens a connection and inspects it.

Python
PostgresSchemaSource(connections: 'PostgresConnectionProvider' = <factory>, inspector: 'PostgresSchemaInspector' = <factory>)
FieldType
connectionsPostgresConnectionProvider
inspectorPostgresSchemaInspector
MethodReturns
load(configuration: 'Configuration')SchemaSnapshot

postgres_type

function

Parses a PostgreSQL type declaration into a SqlType.

Python
postgres_type(declared_type: 'str') -> 'SqlType'
