All references

Every name the packages export, and which package exports it.

This is the index, not the explanation. Each name below is exported from the package it sits under, so from pyoq.query import select is a supported import and anything not listed here is how a package is built rather than what it offers.

The list is rendered from what the packages actually export and the page is held to it by a test, so a name added to a public package fails the build until it appears here.

Public means a package you import from, or a module sitting directly under pyoq. Deeper modules are implementation and are deliberately absent.
