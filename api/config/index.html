APIs

pyoq.config

Reading configuration, and resolving what it names.

What pyproject.toml is read into. Configuration explains the settings themselves; this is the shape they arrive in.

load_configuration

Python
load_configuration(
    project_root: Path,
    *,
    explicit: Configuration | None = None,
    pyproject_path: Path | None = None,
    selected_profile: str | None = None,
) -> Configuration

Reads pyproject.toml under the project root and returns the configuration it holds. pyproject_path names another file, which must be inside the same root. selected_profile overrides selected-profile for this call. explicit bypasses the file entirely, for a caller that already has a configuration.

Configuration

dataclass — everything [tool.pyoq] said.

FieldWhat it holds
project_rootThe containment boundary. Nothing configured may escape it.
codegen_directoryWhere the generated package is written.
codegen_packageIts importable name.
selected_profileWhich profile a command uses when none is named.
profilesEvery configured profile.
schema_snapshotWhere a recorded schema is kept, when one is configured.
codegen_layoutFlat output, or one output package per profile.

active_profile is the profile selected_profile names. generated_path and generated_package are the effective directory and import name for that profile. generation_configurations() returns every profile target when the layout is profiles.

DatabaseProfile

dataclass — one database, however it was named.

FieldWhat it holds
nameThe profile’s name.
dialectWhich database it speaks.
dsnA whole connection string, when one was given.
dsn_environmentA variable holding one, in the older form.
database_pathA SQLite file, for a SQLite profile.
connectionThe structured fields, when those were given instead.
poolThe pool settings this profile carries.
codegen_nameIts generated package segment in profile layout.
schema_snapshotIts recorded schema in profile layout.

A profile carries exactly one way of naming its database. Mixing them is refused when the configuration is read.

ConnectionConfiguration

dataclass — a database named by its parts.

FieldWhat it holds
databaseThe database name. Required.
usernameThe user to connect as. Required.
hostDefaults to localhost.
portDefaults to the dialect’s own port.
passwordOptional.

resolve_dsn(dialect, environment=None) builds the connection string from them, percent-encoding the credentials and the database name, so a password containing @ or # needs no escaping from you.

PoolConfiguration and ResolvedPoolConfiguration

dataclasses — the pool settings a profile carries, before and after their references are resolved.

FieldWhat it holds
minimum_sizeConnections opened with the pool.
maximum_sizeThe most this process will open.
checkout_timeoutHow long a caller waits for one.

resolve(environment=None) turns the first into the second.

Values

NameWhat it is
SettingValueOne profile scalar, either a literal or a whole ${VARIABLE_NAME} reference. resolve(environment) gives a SecretValue.
DataSourceNameThe same, for a whole connection string.
EnvironmentReferenceA variable name, resolved from the environment.
SecretValueA resolved value. Redacted in repr and str; reveal() is how you ask for it.

A value is a literal or a whole reference and nothing in between. See Configuration for the rule and what it refuses.

DatabaseDialect

enum of str — the same three values as Dialect, which is re-exported here under that name too.

CodegenLayout

enum of str with FLAT and PROFILES. Flat is the compatibility default.
