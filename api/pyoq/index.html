Opening a database, and what an open database is.

The top of the package. Four names, and the one most applications start with is connect.

connect

Python
connect(
    dsn: DataSource | None = None,
    *,
    dialect: Dialect | None = None,
    profile: str | None = None,
    project_root: Path | None = None,
    config: Path | None = None,
    pool_policy: PoolPolicy | None = None,
) -> AbstractContextManager[Database]

Opens one process-owned pool, from a profile or from an explicit data source, and closes it when the block ends.

ArgumentWhat it is for
dsnA connection string, instead of reading configuration. Give dialect with it.
dialectWhich database the dsn speaks.
profileWhich configured profile to open. Omitted, selected-profile decides.
project_rootWhere configuration is read from. Defaults to the working directory.
configA pyproject.toml other than the one at the project root, inside the same root.
pool_policyReplaces every pool setting the profile carries, for this call only.
Python
from pyoq import connect

with connect(profile="default") as database:
    ...

The pool belongs to the block. Leaving it closes every connection, whether the block ended normally or by raising.

Database

class — typed operations whose pool is owned by the surrounding context.

MethodWhat it does
transaction()A context manager holding one transaction. Committed when the block ends, rolled back if it raises.
stream(query, *, policy=None)Rows read a piece at a time rather than all at once, for a result too large to hold.

Database is also what the builders are given: using(database).

Dialect

enum of str — which database is being spoken.

MemberValue
Dialect.POSTGRES"postgres"
Dialect.MYSQL"mysql"
Dialect.SQLITE"sqlite"

Because the members are strings, Dialect.MYSQL == "mysql" holds, and a configured value can be compared without converting it.

__version__

str — the installed version, the same one pyoq --version prints.
