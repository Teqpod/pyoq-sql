pyoq.schema

The schema model, and reading one out of a database.

The schema model: what PyOQ reads out of a database, and what generation reads to write your package. Everything here is immutable, and a snapshot serialises to JSON so it can be recorded and compared.

Reading a schema

Python
from pathlib import Path
from pyoq.config import load_configuration
from pyoq.schema import MySQLSchemaSource

snapshot = MySQLSchemaSource().load(load_configuration(Path.cwd()))
for catalog in snapshot.catalogs:
    for schema in catalog.schemas:
        for table in schema.tables:
            print(table.name.value)
NameWhat it does
schema_source_for(dialect)The source for a dialect, without naming its class.
supported_dialects()Which dialects can be inspected.
SchemaSourceThe protocol each source satisfies: load(configuration) returns a SchemaSnapshot.
DialectRoutingSchemaSourceA source that chooses by the configured dialect.

Each dialect has three pieces: a source, a connection provider that opens the connection, and an inspector that reads it.

DialectSourceProviderInspector
PostgreSQLPostgresSchemaSourcePostgresConnectionProviderPostgresSchemaInspector
MySQLMySQLSchemaSourceMySQLConnectionProviderMySQLSchemaInspector
SQLiteSQLiteSchemaSource—SQLiteSchemaInspector

MySQLConnectionSettings holds host, port, user, password and database for a connection opened without a configuration.

SchemaSourceFactory is the type of a callable returning a source.

SchemaSnapshot

dataclass — a whole database as it was read.

MemberWhat it holds
dialectWhich database it came from.
catalogsEverything in it.
capabilitiesWhat that database can express.
format_versionThe format the snapshot is written in.
to_json()The snapshot as text, for recording.
from_json(value)The snapshot a piece of text holds.

SCHEMA_FORMAT_VERSION is the version this build writes. A snapshot recorded under a different one is refused rather than half-read.

Names and types

TypeWhat it is
IdentifierOne name, as the database spells it. Its value is the text.
ObjectReferenceA name with the schema and catalog it sits in.
SqlTypeA declared type: its kind, the source_name the database used, and length, precision, scale, element_type, named_type, metadata where they apply.
SqlExpressionA fragment the database gave back, such as a default or a check, as text.
mysql_type(declared_type)Parses a MySQL type declaration into a SqlType.
postgres_type(declared_type)The same for PostgreSQL.
JsonScalar, JsonValueThe JSON types a value can hold.

What a database can do

Capability names something a database may or may not support, and CapabilitySet answers for one database: supports(capability).

Capability members: CATALOGS, SCHEMAS, VIEWS, MATERIALIZED_VIEWS, ENUMS, ARRAYS, GENERATED_COLUMNS, IDENTITY_COLUMNS, EXPRESSION_INDEXES, PARTIAL_INDEXES, CHECK_CONSTRAINTS.

Enums

TypeKind the broad kind of a declared type

BOOLEAN, SMALL_INTEGER, INTEGER, BIG_INTEGER, DECIMAL, REAL, DOUBLE, STRING, BINARY, DATE, TIME, DATETIME, INTERVAL, UUID, JSON, ENUM, ARRAY, DOMAIN, OTHER

KeyKind PRIMARY, UNIQUE

ReferentialAction what the database does to a child row when the parent moves

NO_ACTION, RESTRICT, CASCADE, SET_NULL, SET_DEFAULT

GeneratedKind how a column’s value is produced

IDENTITY_ALWAYS, IDENTITY_BY_DEFAULT, COMPUTED_STORED, COMPUTED_VIRTUAL

RoutineKind whether a routine answers with a value or is run for what it does

FUNCTION, PROCEDURE

ParameterMode which way a value travels through a routine parameter

IN, OUT, INOUT
