Errors

What PyOQ raises, and what each one means.

Every error inherits from PyOQError, so one except catches everything PyOQ raises and nothing it does not.

Python
from pyoq.errors import PyOQError

They are grouped by the question they answer.

Building a statement

ErrorRaised when
QueryValidationErrorthe statement does not describe a query, such as a SELECT with no projections
QueryStateErrorthe chain was built out of order, such as a source defined twice
ExpressionTypeErrortwo operands cannot be compared, such as text against a number
UnsupportedQueryErrorthe dialect cannot express it, such as a full join on SQLite
ParameterLimitErrorthe statement binds more parameters than the dialect allows
RawExpressionErrora raw fragment is malformed, or the dialect refuses raw fragments
CompilationErrorcompilation failed for a reason the others do not cover

All of these happen before anything runs.

Reading a result

ErrorRaised when
NoResultErrorfetch_one found nothing
MultipleResultsErrorfetch_one found more than one
ResultCardinalityErrora result had a shape the caller did not allow
CollectionDecodeErrora nested collection could not be read back
RowIdentityErrora row cannot be identified, so hydration would merge distinct rows
RelationNotLoadedErrora relation was read that was never fetched
RelationResolutionErrora relation names a table or endpoint the graph cannot resolve
FetchPlanErrora requested relation path, strategy, depth, or limit cannot be planned

Running a statement

ErrorRaised when
QueryExecutionErrorthe database rejected the statement
QueryTimeoutErrorit ran longer than the control allowed
QueryCancelledErrorthe cancellation token was set
ParameterBindingErrora value cannot be bound, such as an unsupported type
TransactionStateErrora transaction was used after it ended
StreamStateErrora stream was read after it closed
ConnectionPoolTimeoutErrorno connection became free in time
ConnectionPoolClosedErrorthe pool was used after closing
ConnectionPoolErrorconnection creation, validation, reset, or disposal failed
TransactionErrora transaction failed outside the more specific state case
StreamErrorstreaming failed outside the more specific state case

Rules and budgets

ErrorRaised when
PolicyViolationErrora policy refused the statement
QueryBudgetExceededErrora scope ran more than its budget allowed

Configuration and generation

ErrorRaised when
ConfigurationFileErrorpyproject.toml is missing or unreadable
ConfigurationValidationErrora setting has the wrong shape
UnknownConfigurationSettingErrora setting PyOQ does not recognise
SecretResolutionErrorthe named environment variable is not set
PathContainmentErrora path escapes the project root
RuntimeSelectionErrorPYOQ_RUNTIME is not auto, native, or python
NativeRuntimeUnavailableErrornative execution was required but no native extension could be loaded
GenerationValidationErrorgenerated Python or the generation plan is invalid
GenerationManifestErrorthe ownership manifest is malformed or incompatible
GenerationDriftError--check found the package out of date
GenerationOwnershipErrora file in the generated directory is not owned by generation
GenerationLockErroranother generation operation owns the project lock
GenerationWriteErrorthe package could not be replaced
NamingValidationErrora source name cannot be converted under the naming contract
NamingCollisionErrortwo schema objects generate the same Python name

Schema

ErrorRaised when
SchemaInspectionErrorthe schema could not be read
SchemaValidationErrorthe schema is not internally consistent
SchemaSerializationErrora recorded schema cannot be decoded or encoded under the schema format
SchemaDriftErrorthe recorded schema and live database differ
OperationUnavailableErrorsomething needed is not installed, such as a driver behind an extra

The broader ConfigurationError, GenerationError, SchemaError, NamingError, RelationError, HydrationError, ExpressionError, QueryError, ExecutionError, and ResultCardinalityError classes are useful catch boundaries for one subsystem. Prefer their named children when recovery differs by cause.

Catching well

Catch the narrowest one that describes what you can do about it. NoResultError from a lookup is a 404. QueryBudgetExceededError is a bug in the code that ran. ConnectionPoolTimeoutError is load. Catching PyOQError around all three treats them alike, which none of them are.
