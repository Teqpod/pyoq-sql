query.pytyped
from decimal import Decimal

from application.database import TITLES, TitleRow
from pyoq.dsl import using

titles = (
    using(database)
    .select(TITLES.ID, TITLES.NAME, TITLES.PRICE)
    .from_(TITLES)
    .where(TITLES.PRICE.gt(Decimal("10.00")))
    .fetch_all()
    .into(TitleRow)
)

Type safety

Schema changes become visible changes.

Regenerate after a migration and incompatible application code fails static checking before it reaches a request.

Security

Values never become SQL structure.

Application values use bound parameters. Identifiers come from generated descriptors or validated identifier APIs.

Performance

Portable by default, accelerated where measured.

The Python runtime remains available while native kernels speed up proven hot paths without requiring Rust from package users.

Observability

Query cost is part of correctness.

Query budgets, repeated-query reporting, metrics, and tracing expose N+1 access and expensive statement shapes.
