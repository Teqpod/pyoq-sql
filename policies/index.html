Running statements

Policies

Rules every statement is held to before it becomes SQL.

A policy is a rule applied to every statement, at the point where it is compiled. Not a convention, not a code review note: a statement that breaks it does not become SQL.

Python
from pyoq.policies import SoftDelete, TenantScope, governed

scoped = governed(database, [
    TenantScope("tenant_id", request.tenant_id),
    SoftDelete("deleted_at"),
])

Everything run through scoped carries those rules. A query you forgot to filter is filtered anyway.

What is available

PolicyDoes
TenantScopeadds a tenant condition to every statement touching the table
SoftDeleteexcludes rows marked deleted
AllowedTablesrefuses a statement touching anything else
RowConstraintadds a condition of your own

They apply to reads and writes alike. An update that would step outside the tenant is refused, not quietly narrowed to nothing.

Why at compilation

It is the one place every statement passes through. A rule applied in a repository method is a rule somebody can go around by writing the query somewhere else; a rule applied at compilation has no other path.

When a statement is refused

Python
from pyoq.errors import PolicyViolationError

The error names the policy and the table, so the fix is obvious.

Getting around it deliberately

Some work genuinely has to see everything: a migration, a support tool, a report across tenants. That is a decision, so it looks like one:

Python
from pyoq.policies import administrative_bypass

with administrative_bypass(audit):
    ...

The bypass takes an audit sink, so the fact that a rule was set aside is recorded rather than assumed. There is no flag that quietly turns policies off.

Raw SQL under a policy

A raw fragment is still checked. A policy that scopes a table applies to a statement that reaches that table however the statement was written, and a dialect that cannot analyse a fragment refuses it under a policy rather than letting it through unexamined.

With a framework

Policies wrap any operations object, so they compose with Django, FastAPI, and Sanic the same way:

Python
from pyoq.django import DjangoOperations

scoped = governed(DjangoOperations(), [TenantScope("tenant_id", tenant)])
